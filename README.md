# Auto Deco

Mod Geode untuk Geometry Dash: dekorasi otomatis di editor.

## Cara pakai
1. Buka editor level.
2. Pilih objek yang mau didekorasi.
3. Tekan tombol **Deco** (pojok kanan atas).
4. Dekorasi langsung ditaruh di sekitar objek terpilih.

## Pengaturan
- **ID Objek Deko** — ID objek yang dipakai sebagai dekorasi.
- **Gaya Deko** — Outline, Atas, Bawah, Kiri-Kanan, Sudut.
- **Taruh di Belakang** — dekorasi di layer B1.
- **Lewati Posisi Terisi** — jangan timpa posisi objek terpilih.
